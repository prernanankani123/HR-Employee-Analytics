# HR Employee Analytics

This project uses Python to analyze employee data and identify patterns in salary, job positions, departments, performance, and employee engagement. Exploratory Data Analysis (EDA) and data visualization are used to understand workforce trends and generate meaningful insights.

## Objectives
- Analyze salary distribution across job positions and departments.
- Explore employee performance, satisfaction, and engagement.
- Examine relationships between salary and other employee attributes.
- Identify workforce patterns using data visualization.
- Generate insights to support data-driven HR decisions.

## Business Questions
The analysis investigates questions such as:
- How are employee salaries distributed?
- How does salary vary across departments?
- Is employee performance associated with salary?
- Is there a visible relationship between employee engagement and salary?
- How does salary vary with the number of special projects handled?

## Tools and Skills
- **Python** — data analysis
- **Pandas** — data manipulation and cleaning
- **NumPy** — numerical analysis
- **Matplotlib** — data visualization
- **Seaborn** — statistical charts and relationship analysis
- **Exploratory Data Analysis (EDA)** — identifying patterns and trends
- **Data preprocessing** — inspecting data types and missing values

## Dataset
- **Records:** 311 employees
- **Features:** 36 columns
- **Data:** Salary, Position, Department, PerformanceScore, EmpSatisfaction, EngagementSurvey, and other employee attributes.

## Project Workflow
1. Data loading and inspection
2. Data cleaning and preprocessing
3. Exploratory Data Analysis (EDA)
4. Statistical analysis and data visualization
5. Interpretation of findings and business insights

## Repository Contents
- *HR Employee Analytics.ipynb* — Python analysis and visualizations
- *HRDataset.csv* — Employee dataset
- *Readme.md* — Project documentation
  
## Key Findings
- Employee salaries vary across job positions and departments.
- Salary shows a weak positive correlation with performance score in this dataset.
- Employee engagement does not show a strong visible relationship with salary.
- The workforce is concentrated in the Production department.
- The relationship between salary and special project count is not consistent.

## Limitations and Future Scope
- The project focuses on exploratory analysis rather than predictive modeling.
- Observed relationships do not establish cause and effect.
- Future work could include employee attrition analysis, deeper workforce comparisons, and an interactive HR dashboard using Power BI.

## Project Takeaway

This project demonstrates practical skills in Python programming, data cleaning, exploratory data analysis, statistical analysis, and data visualization. 
It applies these skills to employee data to identify workforce patterns and present findings that can support further HR analysis.
